BOYZ OF ROSARIO — ADMIN POSITION FIX

Changes:
- Added a position selector to Edit Registered Admin.
- Choices: Founder, Lead, Vice Lead, Secretary, Treasurer, Media 1, Media 2, Moderator 1, Moderator 2.
- Positions assigned to other admins are disabled in the editor.
- Server rejects duplicate positions, even if someone bypasses the browser.
- Admin badge verification returns and displays the position name only (for example, “Moderator 1”), without an “ADMIN POSITION:” label.
- Admin directory cards show assigned positions.
- Admin count label reflects the 9-profile limit.
- Existing admin profiles are migrated automatically with an empty position if they do not already have one.

After Render deploys:

2. Click Edit Admin Profile.
3. Choose an available position and save.
4. Verify that admin's badge at /verify. The result should show only the position name, such as “Moderator 1”.
